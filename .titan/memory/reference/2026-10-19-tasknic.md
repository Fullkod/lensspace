Date: 2026-10-19

- LensSpace is the Tasknic project «LensSpace» (task codes `LEN0001`…), in the same
  workspace as «Turno Flash». Use the `tf-tasknic` skill.

  commit it). The LensSpace key is named «claude-code lensspace» and requires
  `requested_by`: always the person chatting in that session, never assumed.
- Task status lives only in Tasknic: memory and plans cite task codes, never states.
- On Windows/Bash, send texts with accents as a UTF-8 JSON file
  (`--data-binary @file`) and statuses by key (`in_progress`, `in_review`).
